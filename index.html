        From Google Sheets

        In Google Sheets, choose File → Share → Publish to web, pick the tab and Comma-separated values (.csv), then paste the link here. Or choose File → Download → CSV and upload that file above.

        Publishing lets anyone with the link view the sheet. You can stop publishing once the import is done.
